# 아이예뻐 (프로토타입)

보내기 전에 문장을 한 번 더 다듬어 주는 안드로이드 앱.
키보드를 바꾸지 않고, 권한도 요청하지 않고, 앱 전환도 없이 동작한다.

## 어떻게 동작하나

안드로이드의 `ACTION_PROCESS_TEXT` 인텐트를 받는다. 앱을 설치하면 **모든 앱의 텍스트 선택
메뉴**(복사 / 붙여넣기 / 공유 옆)에 "아이예뻐" 항목이 자동으로 등록된다.

1. 카톡·문자·메일 어디서든 평소처럼 메시지를 쓴다
2. 입력창의 글자를 길게 눌러 선택한다
3. 뜨는 메뉴에서 "아이예뻐"를 고른다 (안 보이면 ⋮ 안에 있다)
4. 다듬어진 문장을 확인하고 확정하면, **선택 영역의 글자가 그대로 교체된다**

클립보드를 거치지 않는다. `setResult`로 돌려준 문자열을 호출한 앱이 직접 반영한다.
호출한 앱이 읽기 전용으로 넘긴 경우(`EXTRA_PROCESS_TEXT_READONLY`)에는 교체가 불가능하므로
클립보드 복사로 대체한다.

## 왜 커스텀 키보드가 아닌가

쓰는 순간의 탭 수는 키보드가 가장 적다(1~2탭 vs 3~4탭). 하지만 이탈은 쓸 때가 아니라 설치
직후에 일어난다.

| 방식 | 쓸 때 탭 | 앱 전환 | 설치 직후 비용 |
|---|---|---|---|
| 커스텀 키보드 | 1–2 | 0 | 키보드 활성화 + "입력하는 모든 것을 수집할 수 있음" 경고 수락, 그리고 평생 그 키보드로 타이핑 |
| 접근성 버블 | 2 | 0 | 접근성·오버레이 권한 2개, 상시 오버레이 |
| **텍스트 선택 메뉴** | **3–4** | **0** | **없음** |
| 공유 시트 | 8–9 | 2 | 없음 (대신 매번 앱을 두 번 오감) |

보내는 메시지 200개 중 교정이 필요한 건 한두 개다. 커스텀 키보드는 나머지 198개의 타이핑까지
열화시킨다. 비용은 상시로 내고 효용은 가끔 받는 구조라 오래 못 간다.

부수 효과로 개인정보 노출면도 훨씬 좁다. 이 앱은 사용자가 메뉴를 누른 그 문장 외에는
아무것도 볼 수 없다.

## 빌드

```bash
cd android
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

설치 후 앱을 한 번 열어 Claude API 키를 입력해야 동작한다.

- `compileSdk` 34, `minSdk` 24
- Jetpack Compose (Material 3), OkHttp
- 모델: `claude-sonnet-5`

## 구성

| 파일 | 역할 |
|---|---|
| `ProcessTextActivity.kt` | 앱의 핵심. 선택 메뉴에서 호출되어 투명하게 뜨고, 교정문을 돌려준다 |
| `PolishRepository.kt` | Claude API 호출과 교정 프롬프트 |
| `Tone.kt` | 상대별 톤 정의(선생님·상사·교수님·어른·거래처) |
| `MainActivity.kt` | 설정 화면. 여기서 할 일이 거의 없는 것이 정상이다 |

## 교정 설계

프롬프트의 절반은 "고치라"가 아니라 **"고치지 말라"**는 지시다. 과하게 격식을 씌우면
사용자가 자기 말투를 잃었다고 느끼고 앱을 지운다.

- 원문의 의도와 사실을 바꾸지 않는다 (없는 사정을 지어내지 않는다)
- 이미 공손하면 그대로 둔다
- 존댓말을 겹쳐 쓰지 않는다 — 과공은 비례다
- 길이를 2배 이상 늘리지 않는다
- 같은 사람이 쓴 티가 나야 한다

결과와 함께 "무엇을 왜 고쳤는지" 한 줄(`note`)을 보여준다. 사용자가 다음엔 스스로 쓰게 만드는 장치다.

## 배포 전에 반드시 바꿔야 할 것

- **API 키가 단말에 저장된다.** 프로토타입이라 이렇게 두었다. 배포판은 자체 백엔드를 두고
  앱은 백엔드에만 요청해야 한다. APK에 든 키는 추출된다고 봐야 한다.
- **비밀번호·카드번호 차단.** 지금은 어떤 문장이든 교정한다. 최소한 경고가 필요하다.
- **오프라인·실패 시 동작.** 지금은 에러 메시지 후 재시도뿐이다.
- **iOS에는 이 방식이 없다.** `ACTION_PROCESS_TEXT`는 안드로이드 전용이다. iOS는 공유 시트
  익스텐션이나 커스텀 키보드뿐이라 전략을 다시 세워야 한다.

## 알려진 제약

- 선택 메뉴에 표시되는 항목 수는 제한이 있어, 다른 앱이 많으면 ⋮ 안으로 밀려난다.
- 일부 앱은 입력창 선택 메뉴를 자체 구현해 `PROCESS_TEXT`를 노출하지 않는다.
  실제 기기에서 카톡·문자·Gmail 각각 확인이 필요하다.
- 화면 문구가 한국어로 하드코딩되어 있다.
