시작하기

  1. 원하는 템플릿의 HTML 파일을 복사합니다.
  2. <link rel="stylesheet" href="css/library.css"> 경로만 맞춰줍니다.
  3. 색을 바꾸려면 :root { --brand: #색상; } 한 줄만 덮어쓰면 전체가 따라옵니다.
  4. 다크모드는 <html data-theme="dark"> 로 전환됩니다.
