# 🛰️ STELLAR LAB — 통합과학2 게임형 수행평가 (Google Apps Script)

미션 수행 → **XP·코인 누적 → 연구원 등급 레벨업 → 상점에서 아바타·테마·칭호 꾸미기**.
서버·DB·배포를 **Google Apps Script + 스프레드시트 하나**로 해결합니다.
모든 학생의 점수·답안이 **선생님 스프레드시트에 자동 집계**됩니다.

## 구성 파일
| 파일 | 역할 |
|---|---|
| `Code.gs` | 백엔드 + DB(시트) + **미션·등급·상점 콘텐츠**(여기서만 수정) |
| `Index.html` | 학생 화면 (콘텐츠는 서버가 주입, 저장은 `google.script.run`) |
| `appsscript.json` | 매니페스트(시간대·웹앱 설정) |

---

## 배포 방법 (약 5분)

### 1. 스프레드시트 + 스크립트 만들기
1. [sheets.new](https://sheets.new) 로 **새 스프레드시트** 생성 (이게 DB이자 선생님 대시보드)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭

### 2. 코드 붙여넣기
1. 기본 `Code.gs` 내용을 지우고 → 이 저장소의 **`Code.gs`** 전체를 붙여넣기
2. 왼쪽 **＋ → HTML** 로 파일 추가, 이름을 정확히 **`Index`** 로 (`.html` 자동) → **`Index.html`** 내용 붙여넣기
3. (선택) 프로젝트 설정 ⚙️ → "매니페스트 파일 표시" 켠 뒤 `appsscript.json` 내용 반영
4. 💾 저장

### 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형: **웹 앱**
3. 설정:
   - **다음 사용자로 실행:** 나(선생님) *(모든 데이터가 선생님 시트로 저장됨)*
   - **액세스 권한:**
     - 교내 계정만 쓰게 하려면 **"○○학교 도메인 내 모든 사용자"**
     - 외부/개인 계정 학생도 있으면 **"모든 사용자"**
4. **배포** → 권한 승인(내 계정 선택 → 고급 → 이동)
5. 나오는 **웹 앱 URL** 을 학생들에게 공유 🎉

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 로 재배포해야 반영됩니다.

## 선생님 사용법 (채점·집계)
- 스프레드시트에 자동 생성되는 시트:
  - **`학생진행`** — 학생별 레벨·누적XP·코인·완료수 (한눈에 보기)
  - **`답안`** — 학생별·미션별 답안 전체 (채점용, 학번+미션ID로 갱신)
- 스프레드시트 상단 **🛰️ STELLAR LAB → 📊 요약(랭킹) 새로고침** 메뉴로 XP 순 정렬된 **`요약`** 시트 생성
- 답안 시트를 그대로 수행평가 채점 근거로 활용하거나, 필터/정렬로 확인

## 콘텐츠 수정 (선생님이 자주 바꾸는 곳)
`Code.gs` 상단만 고치면 화면에 자동 반영됩니다.
- `MISSIONS` — 미션 제목/설명/배점(xp·coin)/최소 글자수(min). **수행평가 1·2회 항목에 맞게 교체**
- `RANKS` — 등급 이름·필요 XP
- `SHOP` — 아바타/테마/칭호와 가격·해금 레벨(lv)
- `CFG.SHOW_REAL_NAME_ON_BOARD` — 랭킹에 실명(true)/마스킹(false)

## 채점 신뢰성
- **성적에 쓰는 XP는 서버가 완료 미션 기준으로 재계산** → 브라우저(F12)로 점수 조작 불가
- 코인·꾸미기(아바타/테마)는 학생 편의용이라 신뢰 기반(성적 무관)
- 학생은 **같은 학번**으로 언제든 이어서 수행 가능 (공용 PC는 "🔄 다른 학생으로 전환")

## 개인정보 유의
- 시트에는 이름·학번·답안이 저장됩니다. 시트 공유 범위를 **선생님 본인**으로 유지하세요.
- 학번을 식별자로 쓰므로, 학생에게 **정확한 학번 입력**을 안내하세요.
